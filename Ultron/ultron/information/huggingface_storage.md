# Hugging Face Repository & Checkpoint Storage Guide

This guide instructs the Ultron AI agent on how to automatically create repositories and upload training checkpoints, datasets, and experiment artifacts to Hugging Face.

---

## 1. When to Use Hugging Face

Include Hugging Face creation and upload steps in the execution plan when:
- The task mentions "push to HuggingFace", "upload to HF", "backup model", or "save checkpoints to HF".
- A long-running training job finishes and needs durable off-cluster storage for weights, configs, and evaluation logs.

---

## 2. Zero-Knowledge Authentication & Security Rules
- **CRITICAL SECURITY RULE:** The AI agent must **NEVER** ask for, print, log, or hardcode token strings.
- The Hugging Face API token is stored securely in the system environment variable `HF_TOKEN` (automatically injected from `.env` by the launcher).
- When instantiating `HfApi()`, do **NOT** provide a token argument or hardcode credentials:
  ```python
  from huggingface_hub import HfApi
  api = HfApi()  # automatically detects HF_TOKEN from environment
  ```
- Retrieve the username dynamically:
  ```python
  user_name = api.whoami()["name"]
  ```

---

## 3. Recommended Python Plan Step

The AI agent should create a Python step (`{"type": "python", "name": "Upload to Hugging Face", "code": "..."}`) using `HfApi`:

```python
import os
import sys
from pathlib import Path
from huggingface_hub import HfApi

# 1. Initialize API without explicit token (reads from OS environment)
api = HfApi()

try:
    user_name = api.whoami()["name"]
except Exception as e:
    print(f"Auth error (check that HF_TOKEN is in .env): {e}")
    sys.exit(1)

# Target repository details
repo_name = "act-imitation-learning-checkpoints"
repo_id = f"{user_name}/{repo_name}"
repo_type = "model"  # use "model" for weights/checkpoints, "dataset" for demonstration datasets

# 1. Create the repository if it doesn't already exist (set private=True for safety)
api.create_repo(repo_id=repo_id, repo_type=repo_type, exist_ok=True, private=True)
print(f"Repository ready: https://huggingface.co/{repo_id}")

# 2. Upload directory containing checkpoints, config, and logs
checkpoint_dir = "/home/rijul_chaddha/IsaacLab/ImitationLearning/checkpoints"
if Path(checkpoint_dir).exists():
    api.upload_folder(
        folder_path=checkpoint_dir,
        repo_id=repo_id,
        repo_type=repo_type,
        commit_message="Upload training checkpoints from Ultron job",
    )
    print("✓ Upload completed successfully.")
else:
    print(f"Notice: Checkpoint directory {checkpoint_dir} not found to upload.")
```

---

## 4. CLI Alternative Step

The agent can also execute a shell command step:

```bash
# Upload a whole directory:
huggingface-cli upload <USER_OR_ORG>/<REPO_NAME> /path/to/checkpoints --repo-type model

# Upload a single file:
huggingface-cli upload <USER_OR_ORG>/<REPO_NAME> /path/to/best_checkpoint.ckpt best_checkpoint.ckpt --repo-type model
```

---

## 5. Artifacts Checklist to Include

When packaging artifacts for Hugging Face:
1. **Model Weights:** `.pth`, `.ckpt`, `.pt`, or `.safetensors`.
2. **Config Files:** `config.yaml`, `args.json`, or hyperparameters.
3. **Training & Eval Logs:** Tensorboard events, log files, loss curves, or rollout videos (`.mp4`).
4. **Model Card (`README.md`):** A summary generated by the agent detailing task name, dates, SLURM job ID, and training steps.
