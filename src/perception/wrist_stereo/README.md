# wrist_stereo

Dynamic baseline stereo depth from wrist-mounted HBVCAM cameras. Uses robot kinematics to compute camera poses at runtime, enabling stereo matching even though the cameras are on different arms.

## Why dynamic baseline?

The two HBVCAMs are mounted on separate wrists (one per arm). Unlike a fixed stereo rig, the baseline between them changes as the arms move. This package solves that by:

1. Using forward kinematics (FK) to compute each camera's pose from joint states
2. Computing the relative pose between cameras on the fly
3. Rectifying images for the current baseline
4. Running SGBM stereo matching

## Setup

### 1. Calibrate intrinsics (once per camera)

Point each camera at a checkerboard and capture ~15-20 images from different angles:

```bash
# Left wrist camera
ros2 run wrist_stereo calibrate_intrinsics --ros-args \
  -p camera_topic:=/wrist_left/image_raw \
  -p output_file:=config/left_intrinsics.yaml \
  -p checkerboard_rows:=6 \
  -p checkerboard_cols:=9 \
  -p square_size:=0.025

# Right wrist camera
ros2 run wrist_stereo calibrate_intrinsics --ros-args \
  -p camera_topic:=/wrist_right/image_raw \
  -p output_file:=config/right_intrinsics.yaml
```

**Controls:** SPACE=capture, C=calibrate, S=save, Q=quit

### 2. Calibrate hand-eye (once per camera)

This finds the transform from each camera to its wrist link. Fix a checkerboard in the workspace and move the wrist to 10-15 different poses while viewing it:

```bash
# Left wrist camera
ros2 run wrist_stereo calibrate_hand_eye --ros-args \
  -p camera_topic:=/wrist_left/image_raw \
  -p intrinsics_file:=config/left_intrinsics.yaml \
  -p output_file:=config/left_hand_eye.yaml \
  -p urdf_file:=/path/to/pioneer_bimanual_arm.urdf \
  -p wrist_link:=link6l \
  -p arm_side:=left

# Right wrist camera  
ros2 run wrist_stereo calibrate_hand_eye --ros-args \
  -p camera_topic:=/wrist_right/image_raw \
  -p intrinsics_file:=config/right_intrinsics.yaml \
  -p output_file:=config/right_hand_eye.yaml \
  -p urdf_file:=/path/to/pioneer_bimanual_arm.urdf \
  -p wrist_link:=link6 \
  -p arm_side:=right
```

**Tips:**
- Keep the checkerboard stationary
- Move the wrist to varied poses (different angles, distances)
- Ensure joint states are being published

### 3. Run stereo depth

```bash
ros2 launch wrist_stereo stereo_depth.launch.py \
  urdf_file:=/path/to/pioneer_bimanual_arm.urdf
```

Or run the node directly:

```bash
ros2 run wrist_stereo stereo_depth_node --ros-args \
  -p urdf_file:=/path/to/pioneer_bimanual_arm.urdf \
  -p left_intrinsics:=config/left_intrinsics.yaml \
  -p right_intrinsics:=config/right_intrinsics.yaml \
  -p left_hand_eye:=config/left_hand_eye.yaml \
  -p right_hand_eye:=config/right_hand_eye.yaml
```

## Topics

### Subscribed
- `/wrist_left/image_raw` (sensor_msgs/Image) — left wrist camera
- `/wrist_right/image_raw` (sensor_msgs/Image) — right wrist camera  
- `/joint_states` (sensor_msgs/JointState) — robot joint positions for FK

### Published
- `/wrist_stereo/depth` (sensor_msgs/Image, mono16) — depth in mm
- `/wrist_stereo/points` (sensor_msgs/PointCloud2) — 3D points (optional)

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `urdf_file` | - | Path to robot URDF (required) |
| `left_wrist_link` | `link6l` | Left wrist link in URDF |
| `right_wrist_link` | `link6` | Right wrist link in URDF |
| `min_depth` | 0.05 | Minimum depth in meters |
| `max_depth` | 0.5 | Maximum depth in meters |
| `num_disparities` | 128 | SGBM num disparities (must be ×16) |
| `block_size` | 5 | SGBM block size (odd, 3-11) |
| `publish_points` | true | Publish point cloud |

## File structure

```
└── wrist_stereo/

```
